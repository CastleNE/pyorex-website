# PyOrex Website

Official website and PyOrex HUB for the PyOrex ecosystem.

## Structure
- **PyOrex Software** — product, downloads, documentation and project support.
- **PyOrex HUB** — curated exploration intelligence for exploration and economic geologists.

Built with Astro and intended for deployment on Cloudflare Pages.

### Development
```bash
npm install
npm run dev
npm run build
```

Cloudflare Pages build: `npm run build` → output directory `dist`.
